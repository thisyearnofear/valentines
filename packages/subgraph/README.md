# @lub-u/subgraph

The Graph subgraph for lub-u (ClickLub contract on Linea mainnet).

## Deployment instructions

1. Install dependencies:  
   `yarn` or `npm install`

2. Generate types:  
   `npm run codegen`

3. Build subgraph:  
   `npm run build`

4. Deploy (replace <YOUR_SUBGRAPH_SLUG>):  
   `npm run deploy`

See [The Graph documentation](https://thegraph.com/docs/) for more details.
